# muse-city-lab — SENDAI Real-Data Scroll Prototype

「JAPAN — THE CITY COLLECTION」の実データ方式を検証する独立プロジェクトの公開用リポジトリ。
本編（Three.js プロシージャル方式、Hiro2821/japan-city-collection）とは別に、CesiumJS + 国土交通省 PLATEAU の実データで「スクロール連動のリアルタイム都市」がどこまで成立するかを試作・検証しています。

**公開ページ: https://hiro2821.github.io/muse-city-lab/**

## 試作の内容

- 仙台の実データ都市（PLATEAU 仙台市 3D都市モデル 2024年度・青葉区 LOD2 テクスチャ付き建物＋PLATEAU-Ortho 2023 航空写真＋国土地理院 DEM 地形）を CesiumJS で表示
- 実座標カメラルート: 仙台駅 → 青葉通 → 定禅寺通 → 一番町 → 青葉城址（広瀬川越しのフィナーレ）
- 駆動は本編と同じ決定論的スクロール制御: 600svh トラック、`p = clamp(-top/(trackH-stageH))`、`t = min(1, p/0.94) × 54`、逆スクロールで同じ p = 同じ構図

### URL パラメータ

| パラメータ | 値 | 意味 |
|---|---|---|
| `?route=` | `v1`（既定） / `v2` | v2 は青葉通・定禅寺通・一番町に高度 6〜8m の街路レベルキーを追加 |
| `?grade=` | `day` / `dusk`（既定） / `night` | 太陽時刻を正とした時間帯プリセット（12:00 / 17:20 / 19:30 JST） |
| `?terrain=` | `ellipsoid`（既定） / `dem` | dem は国土地理院 dem_png 地形を使用 |
| `?heightfix=` | `on`（既定） / `off` | カメラ高度の基準面補正（基盤楕円体高 = DEM標高 + ジオイド 40.67m） |
| `?lights=` | `on` | 窓明かり点群の重ね物試作（本採用ではない到達度検証用） |
| `?debug=` | `1` | p / t / タイル読み込み状態のデバッグ表示 |

注: `?renderer=model`（GLB 個別読み）と `?tiles=proxy`（ローカル検証用プロキシ）は公開版では利用できません（ローカル検証環境専用）。

## 検証状況（2026-11-22、デスクトップ検証まで完了）

確認できたこと:

- 地表が描画されない問題を解決（原因は航空写真レイヤの `minimumLevel` 指定）
- カメラ高度の基準面ずれを補正し、街路レベル（対地 6〜8m）の構図が成立することを確認
- 地理院 DEM 地形で建物足元と地表の段差が構図内で見えなくなるところまで到達
- 夜は標準機能だけでは「灯りのない暗い街」止まりで、窓明かりは建物に整合した重ね物が別途必要と判明
- 転送量は初期表示で約14MB、通し表示では百MB級（内訳は PLATEAU 建物タイルが約85〜90%）。本編のバンドル約944KB とは桁が違う

未検証:

- **iPhone 実機の fps・発熱・メモリ・実回線でのタイル追随**（この公開はその実機確認のためのものです）
- フィナーレで白い無テクスチャ建物が多い理由（LOD選択か区域的な LOD1 のみ収録か）

本編との比較表は [docs/COMPARISON.md](docs/COMPARISON.md) にあります。

## 配信方法について

Cesium 本体はリポジトリに含めず、jsDelivr CDN（cesium@1.124.0）から読み込んでいます。PLATEAU 等のタイルは各配信元から直接読み込みます。
